# Obsidian GSync 個人用OAuth設定

管理者本人がObsidianとGoogle Driveを同期するために設定したOAuthアプリの説明・プライバシーポリシーです。GSync公式プロジェクトではありません。

- 説明：https://omosin1992.github.io/obsidian-gsync-oauth/
- プライバシーポリシー：https://omosin1992.github.io/obsidian-gsync-oauth/privacy.html
- 利用条件：https://omosin1992.github.io/obsidian-gsync-oauth/index.html#terms
- GSync公式：https://github.com/dg0988/ObsidianGSync

GitHub Pagesの公開元は `main` ブランチのルートです。外部スクリプト・解析・フォームはありません。Google OAuthの審査承認や本番移行の完了を示すサイトではありません。

## 機密情報を保存しない

このリポジトリにはOAuthクライアント情報、Client secret、トークン、認証コード、プラグインの設定データ、VaultやDriveの実ファイルを保存しません。Issuesにも投稿しないでください。

## 構成

- `index.html`：個人用アプリの説明と利用条件
- `privacy.html`：データ取り扱いの説明
- `README.md`：この文書

説明内容は2026年10月15日に確認した公式資料に基づきます。インストール済みGSyncの版は未確認です。認証方式・リダイレクト先・スコープを変更する場合は、実態に合わせて説明を見直してください。

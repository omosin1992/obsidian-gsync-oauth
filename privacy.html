プライバシーポリシー

対象：「Obsidian GSync」個人用OAuthアプリ
管理者：GitHubユーザー omosin1992
更新日：2026年10月15日

1. 適用範囲

管理者本人のGoogleアカウントを使う個人用OAuth設定と、この説明サイトに適用します。管理者はGSyncプラグイン自体の開発者ではありません。以下のプラグインの動作説明は、GSync公式READMEと公開ソースに基づきます。インストール済みバージョンや将来の変更により動作が異なる可能性があります。

2. アクセスするデータと目的

GSyncは、ObsidianのローカルVaultと指定したGoogle Driveフォルダの同期のため、ファイル名・フォルダ情報・更新日時・サイズ・チェックサム等のメタデータ、および同期対象ファイルの内容にアクセスします。ファイルの作成・更新・ダウンロード、および設定に応じたゴミ箱への移動を行います。

OAuthのdriveスコープはDrive全体への広い権限を与えます。同期先の指定だけではGoogle側の権限は限定されません。取得データは個人用同期の目的にのみ使用し、広告、販売、データ仲介、AIモデルの学習には使用しません。Google APIから受け取る情報の利用・他のアプリへの転送は、Google API Services User Data Policy（Limited Use要件を含む）に従います。

3. 保存先と保持期間

同期されたファイルは利用者の端末とGoogle Driveに保存され、利用者が削除するまで保持されます。ごみ箱・バックアップの保持期間は各サービスの設定や規約に従います。GSyncの公式説明では、OAuthクライアント情報とトークンは各端末のプラグイン設定ファイルに保存されます。この説明サイトの管理者は、別の同期サーバーやトークン保管サーバーを運営していません。

プラグインの設定ファイルは機密情報として保護し、公開リポジトリや問い合わせに含めないでください。

4. 通信先と認証時の第三者ページ

同期・認証ではGoogleの認証エンドポイントとGoogle Drive APIに通信します。現在の構成では、GSync開発者がGitHub Pagesで提供する https://dg0988.github.io/ObsidianGSync/callback.html をサインイン時のリダイレクト先に使用します。

このページへのリクエストには一時的な認証コードとstateが含まれ、stateにはVault名が含まれる場合があります。公開ソースでは、それらを端末のObsidianへ引き渡し、ブラウザーのアドレスから除去する処理になっています。公式READMEはPKCEの使用を説明していますが、第三者が管理するページの将来の内容やホスティング側のログを、この個人用設定の管理者が保証することはできません。

Google、Obsidian、GitHubなど各提供者による情報処理には、それぞれのプライバシーポリシーが適用されます。

5. 説明サイトの情報収集

本サイトは静的HTMLで、管理者独自のアクセス解析、広告、Cookie、入力フォーム、認証処理は設置していません。GitHub Pagesのホスティングでは、GitHubがセキュリティ目的で訪問者のIPアドレスなどを記録することがあります。詳しくはGitHubのプライバシーに関する声明をご覧ください。公開Issuesに投稿した内容は第三者にも閲覧されます。

6. アクセスの取り消しと削除

Googleアカウントの接続管理から、このOAuthアプリへのアクセスを取り消せます。これにより同期の認可を無効化できますが、すでに端末やDriveに保存されたファイルは自動削除されません。必要なデータを確保したうえで、端末側の設定・トークン・ファイルとDrive側のデータを利用者自身が管理してください。プラグインを無効化しただけではGoogle側の認可が取り消されるとは限りません。

7. 連絡・変更

連絡先は本リポジトリのIssuesです。Client secret、トークン、認証コード、ノート本文などを投稿しないでください。実際のデータ取り扱いに変更があれば本ページを更新します。
